# Divinity: Original Sin 2 — Detonado Interativo PT-BR v1.0.0

Primeira versão pública do detonado interativo em PT-BR para **Divinity: Original Sin 2 — Definitive Edition**.

## O que esta versão inclui

- 192 etapas de campanha.
- Rastreamento de 97 conquistas.
- Progresso salvo localmente.
- Progresso individual de objetivos.
- Exportação e importação de save do guia em JSON.
- Modo Rota.
- Busca global e navegação por etapas.
- Painéis de campanha para acompanhar missões, decisões, segredos, grupo e outros estados.
- Biblioteca de builds e configuração do grupo.
- Mapas e referências integradas.
- Interface adaptada para desktop e dispositivos móveis.
- Execução offline: basta extrair o ZIP e abrir `index.html`.

## Instalação

Não há instalação.

1. Baixe `Detonado_DOS2_DE_Interativo_PTBR_v1.0.0.zip`.
2. Extraia o arquivo.
3. Abra `index.html` no navegador.

> O progresso fica salvo no navegador. Use as opções de exportar/importar progresso para criar uma cópia ou mudar de dispositivo.
